# Coffee Landing Page — Model Test: "deepseek"

Self-contained single file. Open `index.html` in any browser — no build step, no npm.

**Stack:** React 18 (UMD) + Babel standalone + Tailwind CSS (CDN) + Lucide icons.
**Brand:** AURELIA — Specialty Coffee & Bakery (fictional).
**Typography:** Fraunces (display serif) + Outfit (sans).
**Palette:** cream / linen / beige / espresso brown / caramel / gold.

## Art direction (vs "Beam" version)
- Editorial layout: bottom-weighted cinematic hero, centered split navbar
- Numbered signature menu with hover image-swap panel (desktop)
- Offset two-image story collage with pull quote
- Full-bleed parallax atmosphere band + photo strip
- Bakery done as a 3-column card grid
- Testimonial carousel with prev/next + dots
- Scroll progress bar, back-to-top button

## How to compare models
Open both side by side:
- `coffee by Beam/index.html`
- `coffee by deepseek/index.html`
